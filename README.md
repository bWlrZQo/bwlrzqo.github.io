# bwlrzqo.github.io

This repository contains the GitHub Pages site for all apps of the workspace.
The site URL is https://bwlrzqo.github.io/.

## Structure
- `index.html`: The main page. It has a list of the apps.
- `assets/site.css`: The shared style sheet.
- `<app>/support/`: The support page of an app. App Store Connect uses this page as the Support URL.
- `<app>/privacy/`: The privacy policy of an app.
- `<app>/terms/`: The terms of use of an app.
- `.nojekyll`: GitHub Pages does not use Jekyll for this site.

## Contact
All apps use `bwlrzqodev@proton.me` as the support contact.

## Publish
Commit the changes. Then push to `main`. GitHub Pages publishes the site in approximately 1 minute.

## Rules
Put only website files in this repository. Do not put app code or secrets in it. The repository is public.
